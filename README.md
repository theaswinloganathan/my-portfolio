# Data Portfolio Index

## Overview
This repository serves as a centralized showcase of all my data‑analysis projects. Each project lives in its own sub‑directory (or separate repository) and follows a consistent documentation structure, making it easy for recruiters and collaborators to explore my work.

## How to Explore
- **Navigate** to a project folder to find its own `README.md` with detailed documentation, data sources, and execution instructions.
- **Run** notebooks locally using `conda env create -f environment.yml` or `pip install -r requirements.txt`.
- **View** Power BI dashboards via the published web link (if public) or request access.

---

## Adding a New Project
1. Create a new folder (e.g., `my-new-project`).
2. Add a `README.md` based on the **Project Documentation Template** located in `templates/PROJECT_DOC_TEMPLATE.md`.
3. Commit and push – the central index will automatically list it in the `Projects` section of this README.
